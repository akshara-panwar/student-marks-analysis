# Student Performance Analysis Project

## About This Project
I created this project while learning Python for data analysis.

The main goal of this project is to analyze student marks and understand their performance in different subjects.


## Tools Used
- Python  
- Pandas  
- Matplotlib  


## What I Did
- Created a dataset of students and their marks  
- Calculated total marks, average marks, and percentage  
- Assigned grades based on percentage  
- Found the topper student  
- Ranked students based on total marks  
- Visualized student performance using a bar chart
  

## Key Insights
- Some students performed very well across all subjects  
- Total marks help in identifying the topper  
- Grades make it easy to understand performance level  
- Visualization helps compare students easily
- Ranking helps compare student performance more clearly  


## Conclusion
This project helped me understand how to work with data using Python. I learned how to perform calculations, analyze results, and visualize data in a simple way.
